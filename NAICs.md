# Tradex Holdings LLC — IT Contract NAICS Reference

This guide helps the Tradex team find, review, and categorize federal IT contract opportunities using the **2022 U.S. NAICS classifications**.

This is a broad search reference, not an exhaustive list of every industry involving IT. Listing a code here does not mean Tradex offers that service or is registered under that code.

## 8. Team Workflow

1. **Find opportunities:** Search using relevant NAICS codes and keywords.
2. **Review requirements:** Read the notice, solicitation, attachments, and amendments.
3. **Record the opportunity:** Create a GitHub issue using the template above.
4. **Assess feasibility:** Explain whether Tradex can meet the requirements and identify any gaps.
5. **Recommend a decision:** Record a Bid, No Bid, or Further Review Needed recommendation.
6. **Assign approved work:** Tradex assigns responsibility for preparing bid materials.
7. **Track submission and results:** Monitor deadlines, amendments, submission confirmation, and award outcomes.

## 9. Important Notes

- This reference supports opportunity searches and does not replace reviewing the solicitation.
- A matching NAICS code alone does not establish eligibility or technical capability.
- Record the NAICS code stated in the solicitation when categorizing an opportunity.
- Check restrictions on personnel location, citizenship, remote access, data handling, and subcontracting before assigning work.
- Follow the submission instructions in the solicitation. A notice appearing on SAM.gov does not necessarily mean the response is submitted through SAM.gov.
- Sources Sought notices and RFIs generally request information for market research. Follow the specific response instructions in each notice.
- 513210 is the 2022 NAICS code for Software Publishers. Historical records may use the older code 511210.
- Review this guide when NAICS classifications change.
